# Welcome to nano.md

A small desktop app for reading and editing Markdown files, with a terminal
pane for working with your agent while the document stays in view.

| Shortcut | What it does |
|---|---|
| `Ctrl+E` | Switch between the rendered view and editing the source |
| `Ctrl+O` | Open a file |
| `` Ctrl+` `` | Show the terminal: start your agent here |

Use `Cmd` instead of `Ctrl` on macOS.

More in the [README](https://github.com/odysseia06/nanomd#readme).
